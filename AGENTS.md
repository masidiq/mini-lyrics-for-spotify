# Project instructions

## Local build and release artifacts

- Use `artifacts/latest` as the only local output folder for new published versions.
- Update the existing folder so it contains only the newest version. Do not create versioned build, release, update, or verification folders.
- Store verification output under `artifacts/latest/verification`.
- Preserve required third-party notices and licenses with the published application.
- Close the running application through its tray menu before replacing its executable.
